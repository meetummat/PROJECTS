# 🎯 Number Guessing Game

A simple Python game where the computer generates a random number between **1 and 100**, and the player has to guess the number.

The program gives hints after every incorrect guess and counts how many attempts the player takes to find the correct number.

## 🧠 What I Practiced

- `random` module
- `random.randint()`
- `while` loop
- `if`, `elif` conditions
- User input with `input()`
- Type conversion using `int()`
- Variables and counters
- f-strings

## 🎮 How It Works

1. The computer generates a random number between 1 and 100.
2. The player enters a guess.
3. If the guess is too high, the program says **"Lower number please"**.
4. If the guess is too low, the program says **"Higher number please"**.
5. The game continues until the correct number is guessed.
6. The program displays the number of attempts taken.
7. A performance message is displayed based on the number of attempts.
