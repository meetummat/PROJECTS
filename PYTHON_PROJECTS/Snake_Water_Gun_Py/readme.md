# Snake Water Gun Game 🐍💧🔫

A simple command-line **Snake Water Gun game** built with Python.

## 🎮 About the Game

Snake Water Gun is a simple game similar to Rock Paper Scissors.

The rules are:

* 🐍 **Snake beats Water**
* 💧 **Water beats Gun**
* 🔫 **Gun beats Snake**
* Same choice → **Draw**

The computer randomly selects one of the three choices, and the player enters their choice.

## ▶️ How to Run

### 1. Make sure Python is installed

Check your Python installation:

```bash
python --version
```

### 2. Run the program

Open the project folder in your terminal and run:

```bash
python main.py
```

### 3. Enter your choice

When prompted, enter one of:

```text
snake
water
gun
```

## 💻 Example

Another possible result:
